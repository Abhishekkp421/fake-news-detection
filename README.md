# Fake News Detection System

A Machine Learning based web application that detects whether a news article is Real or Fake.

## Features
- Detects fake and real news
- Text preprocessing using NLP techniques
- Machine Learning model for prediction
- Simple web interface using Streamlit

## Technologies Used
- Python
- Pandas
- Scikit-learn
- NLP
- Streamlit

## Dataset
- Fake and True news dataset from Kaggle

## Project Description
This project uses machine learning algorithms to classify news articles as fake or real. The model is trained on a dataset and deployed using Streamlit for easy user interaction.
